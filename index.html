How we got here

Five eras of AI, and what made each one possible.

  1. 1950s to 1990s

    Symbolic AI

    People write the rules. The computer follows them.

    Made possible by: the first computers.

    • 1956The name "artificial intelligence" is coined.
    • 1997Deep Blue beats the chess champion by searching millions of moves.

  2. 1990s to 2010s

    Machine learning

    The computer learns patterns from examples.

    Made possible by: lots of digital data, thanks to the internet.

    • 2000sSpam filters learn from millions of emails.

  3. 2012 on

    Deep learning

    Big neural networks learn from huge amounts of data.

    Made possible by: GPUs, chips first built for video games.

    • 2012A network learns to recognize photos, not rules.
    • 2016AlphaGo masters Go by trial and reward.

  4. 2017 on

    Generative AI

    Models create text, images and code.

    Made possible by: Transformers, and text from across the internet.

    • 2017Transformers: the T in GPT.
    • 2022ChatGPT: anyone can chat with a model.

  5. Now

    Agentic AI

    AI uses tools, makes choices and acts.

    Made possible by: models that can call tools and finish longer tasks.

    • NowCoding and research agents. And the agent you'll build.

What is an AI agent?

Hands up, 1 min

You've used chatbots like ChatGPT. What do you think makes something an AI agent?

01A modelReads, thinks and writes. The same kind of AI as ChatGPT.
02ToolsLooks up live data or does things, instead of guessing.
03A choiceDecides its next step from what it finds.
04MemoryKeeps notes and reads them next time.
05A triggerA message or a clock starts it, even while you sleep.

An AI agent is AI that can take action on its own.

It needs a model, tools and a choice. Add memory and a trigger, and it keeps working even when you're not there.

When agents go wrong

Discuss, 2 min

An agent can look things up and act on its own. How could that go wrong? Name as many ways as you can.

HallucinationsIt makes up facts or numbers, sounds sure, then acts on them.
Prompt injectionIt follows orders hidden in a web page, email or file it reads.
Excessive permissionsIt can reach more than its task needs, so one mistake hits real data.
No human in the loopIt deletes, pays or sends with no one approving first.
AI-powered attacksIt finds and uses security holes faster than people can respond.

Which of the five ways shows up in each story?

April 2026

The 9-second mistake

A coding agent was fixing a small problem in a test system. It had a key that also opened the company's live system. It deleted the live database and its backups in 9 seconds. Nobody asked it to.

Sources: TechSpot, Decrypt.

July 2026

An AI agent hacks Hugging Face

Hugging Face hosts many of the world's open AI models. Over one weekend, an AI agent broke in on its own. It took over 17,000 actions and reached internal data and login keys. Hugging Face caught it using AI.

Sources: BleepingComputer, TNW.
